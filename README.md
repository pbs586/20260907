# 춘천 발전 예산 모바일 웹자보 - GitHub Pages 배포 가이드

본 폴더(배포용_GitHub)에 담긴 파일들을 그대로 GitHub 저장소에 올리면 무료 모바일 웹사이트 URL이 생성됩니다.

---

## 📁 배포 폴더 구성
1. index.html : 모바일 최적화 메인 웹자보 파일 (카카오톡/문자 공유 메타태그 포함)
2. 소양2교.jpg : 상단 및 비주얼 카드 배경 이미지
3. 허영의원_누끼.png : 허영 의원님 투명 배경 고해상도 인물 사진

---

## 🚀 1분 만에 GitHub 무료 웹페이지로 배포하는 방법

### 1단계: GitHub 저장소(Repository) 만들기
1. GitHub(https://github.com/) 로그인 후 우측 상단 [+] -> [New repository] 클릭
2. Repository name 입력 (예: chuncheon-budget 또는 2027-budget)
3. Public(공개)으로 설정 후 [Create repository] 클릭

### 2단계: 파일 업로드
1. 생성된 저장소 화면에서 'uploading an existing file' 링크 클릭
2. 본 폴더(배포용_GitHub)에 있는 3개 파일(index.html, 소양2교.jpg, 허영의원_누끼.png)을 드래그 앤 드롭
3. 하단 초록색 [Commit changes] 버튼 클릭

### 3단계: 웹사이트 활성화 (GitHub Pages 켜기)
1. 저장소 상단 메뉴의 [Settings] (톱니바퀴) 클릭
2. 왼쪽 사이드바에서 [Pages] 클릭
3. Build and deployment 항목의 Branch 설정을 None -> main(또는 master)으로 변경하고 [Save] 클릭
4. 약 1분 후 상단에 배포된 웹 주소가 표시됩니다:
   * 배포 주소 예시: https://[아이디].github.io/[저장소이름]/

---

## 📲 문자(LMS) 및 카카오톡 전송 시 활용법
* 생성된 주소를 buly.kr 또는 bit.ly 같은 무료 단축 URL 서비스에 넣어 짧은 링크(예: https://buly.kr/춘천예산)로 변환해 문자에 넣으시면 됩니다.
